# Demo Project

## Overview
This project is designed to test the "login page" feature of the application hosted at app.vwo.com. It includes a comprehensive test plan, source code, and automated tests using Playwright.

## Project Structure
```
demo
├── test-plans
│   └── login-page-test-plan.md
├── src
│   ├── app.js
│   └── tests
│       └── login.test.js
├── package.json
└── README.md
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies by running:
   ```
   npm install
   ```
4. To run the tests, use the following command:
   ```
   npm test
   ```

## Features
- Comprehensive test plan for the login page.
- End-to-end testing using Playwright.
- Organized project structure for easy navigation and maintenance.
